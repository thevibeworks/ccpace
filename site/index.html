PyPI package ↗Claude Code plugin ↗

Measured usage. Estimated forecasts.

Usage comes from provider OAuth endpoints. Claude history and caches are shared with claude-code-statusline; Codex has its own account-scoped store. Forecasts use that history; they are not promises of available capacity.

ccpace watches and warns. It does not control agent execution or redeem Codex resets. Provider endpoints can change. Claude tokens may refresh through the existing OAuth flow; Codex auth files stay read-only. Usage data stays local unless you configure notification destinations.
